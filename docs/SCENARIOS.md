# 상황별 처리 흐름 (시연 시나리오)

등장인물: **사용자A**(`userA`) · **사용자B**(`userB`) · **사용자C**(`userC`) · **관리자**(`manager`)
— 모두 비밀번호 `1234`. 관리자도 [관리자] 탭에 처음 들어갈 때 관리자 코드를 한 번 입력한다.

시연은 판정 기준을 짧게 두고 한다: 관리자 탭 → 판정 기준 → **[시연 모드]** → 저장
(장기 이석·사석화·무단 점유 **1분**, 판단 불가 30초, 체크인 제한 2분, 확인 필요 후 자동 반납 2분, 사전 경고 15초 전).

각 상황은 콘솔 한 줄로 바로 만들 수 있다(카메라 없이 시연):

```bash
python manage.py scenario 1 --demo-settings   # 1 · 1b · 2a · 2b · 3 · reset
```

상태 분류(관리자 대시보드 색): ⬜ 빈자리 · 🟩 정상(사람이 이용 중) · 🟧 이석(일시/장기) · 🟥 무단 점유 · ⬛ 판단 불가, `!`(우측 상단) = 관리자 확인 필요, 노란 점(좌측 상단) = 짐 있음(짐 감지 ON)

---

## 1. userA가 예약했는데 userB가 마음대로 착석

| 시점 | 무슨 일이 | 시스템 판정 | 누가 무엇을 |
|---|---|---|---|
| 0초 | A가 A-1 예약(체크인 전), B가 A-1에 앉음 | 🟩 정상 · 착석(체크인 전) — 앉은 사람이 예약자인지 아직 모름 | — |
| | B가 A-1 QR을 찍음 | 예약된 좌석 → B는 예약 불가 ("예약된 좌석입니다 · 관리자 호출") | 사전 차단 |
| A 도착 | A가 자기 자리에 B가 앉은 것을 봄 | | A: 좌석 QR 화면 또는 [내 자리] → **[내 자리에 다른 사람이 앉아 있어요]** |
| 즉시 | | 관리자 화면(어느 탭이든)에 **📣 팝업** + 소리, 조치 목록에 "내 예약 좌석에 다른 사람이 앉아 있음" | 관리자: 팝업 → [A-1 좌석 처리하기] |
| 1분 | (그사이 아무도 QR 체크인 안 함) | 🟥 **무단 점유 · 체크인 누락** `!` | 시스템도 확인 필요로 올림 |
| 처리 | 관리자가 현장에서 B에게 안내 | | 관리자: **[착석자 퇴실 안내 완료]** → A-1 비어 있음 + 신고 처리 완료 (B에게는 빈자리 예약 안내) |
| 끝 | A가 A-1 QR로 체크인 | 🟩 정상 이용 | — |

- 다른 방법: A를 다른 빈자리로 옮겨 주기 → [예약자 다른 좌석으로].

### 1-b. A가 체크인하고 잠깐 나간 사이 B가 앉음
카메라는 "사람 있음"만 보므로 🟩 정상 이용으로 보인다(누가 앉았는지는 모름 — 얼굴 인식은 하지 않음).
→ A의 **[내 자리에 다른 사람이 앉아 있어요]** 신고가 유일한 단서 → 관리자 팝업 → 관리자가 좌석 상태를 **무단 점유**로 지정
(🟥, A에게 "다른 이용이 확인됐어요" 알림) → 현장 안내 → [퇴실 안내 완료].

## 2. userC가 체크인했는데 자리에 없음 / 반대로 QR 체크인 없이 앉음

**2-a. 예약·QR 체크인 후 1분 이상 자리에 없음**

| 시점 | 시스템 판정 | 누가 무엇을 |
|---|---|---|
| 0초 | 🟧 이석(일시) · 일시 이석 | — |
| 45초 | (장기 이석 15초 전) | C에게 **사전 경고** 알림 "돌아오지 않으면 장기 이석" |
| 1분 | 🟧 **이석(장기) · 장기 이석** `!` → 조치 목록 | C에게 "장기 이석으로 표시됐어요 · n분 뒤 자동 반납" / 관리자: [강제 반납] 또는 [예약자 경고] |
| 3분 | (관리자가 처리하지 않으면) **자동 강제 반납** | 처리 이력에 '자동 강제 반납' |

C가 그사이 돌아와 앉으면 바로 🟩 정상 이용으로 돌아간다.

**2-b. 예약하고 QR 체크인 없이 착석**

| 시점 | 시스템 판정 | 누가 무엇을 |
|---|---|---|
| 0초 | 🟩 정상 · 착석(체크인 전) — 앉고 QR을 찍기까지 기다림 | C 화면: "착석이 확인됐어요. n초 안에 좌석 QR로 체크인해 주세요" |
| 1분 | 🟥 **무단 점유 · 체크인 누락** `!` | C에게 "체크인해 주세요" 알림 / 관리자: 본인 확인 후 [대리 체크인] 또는 C에게 QR 체크인 안내 |
| C가 QR 체크인 | 🟩 정상 이용 — 처리 필요 알림 자동 해소 | — |

## 3. userA가 A-1을 예약하고 착각해서 B-1에 앉음

| 시점 | 시스템 판정 | 누가 무엇을 |
|---|---|---|
| 0초 | A-1 ⬜ 입실 대기 / B-1 🟩 착석 감지(체크인 전) | — |
| A가 B-1 QR을 찍음 | B-1 화면: "**예약한 좌석은 A-1이에요.** 지금 찍은 QR은 B-1 좌석이에요" | A: A-1로 가서 A-1 QR로 체크인, 또는 **[A-1 → B-1(으)로 바꾸기]** |
| 1분 | B-1 🟥 **무단 점유** `!` (A-1은 아직 입실 대기) | 관리자: B-1 상세 → **[다른 좌석 예약자가 앉음 → 이 좌석으로]** → A의 예약 선택 → 예약을 B-1로 옮기고 바로 체크인 |
| 처리 후 | B-1 🟩 정상 이용, A-1 ⬜ 빈자리 | A에게 "좌석이 B-1(으)로 옮겨졌어요" 알림 |
| (아무도 처리 안 하면) 2분 | A-1 🟧 이석(장기) · 미입실 `!` → 2분 뒤 예약 자동 취소 | |

- A의 예약 QR 체크인은 **예약한 좌석의 QR**로만 된다(B-1 QR로 A-1 체크인 불가) — 원격·대리 체크인 방지.

## 더 많은 상황 (4~16)

시연 기준(1분) 판정 값으로 정리했다. ⬜ 빈자리 · 🟩 정상 · 🟧 이석 · 🟥 무단 점유 · ⬛ 판단 불가 · `!` 관리자 확인

### 4. 예약만 하고 오지 않음
1. A가 A-1 예약 → ⬜ 입실 대기
2. 마감 15초 전 → A에게 "체크인 마감 n초 전" 알림
3. 2분(체크인 제한) → 🟧 **이석(장기) · 미입실** `!` — 관리자: 예약 취소 또는 늦게 왔으면 대리 체크인
4. 4분 → 예약 **자동 취소**, A에게 알림

### 5. 이용 시간을 연장하고 싶음
1. 체크인 후 이용 시간 120분
2. 종료 30분 전부터 [연장] 가능 → +60분 (너무 이르면 "종료 30분 전부터 연장할 수 있어요")
3. 최대 2회 — 3번째는 "연장은 최대 2회까지 가능해요" (관리자 연장은 횟수와 별개)

### 6. 이용 시간이 끝났는데 계속 앉아 있음
1. 종료 시각 → 예약 **자동 종료(시간 만료)**
2. 계속 앉아 있으면 🟩 착석 감지 → 1분 뒤 🟥 **무단 점유** `!` (종료 시점부터 센다)
3. 관리자: 새로 예약하도록 안내하거나 [현장 배정]

### 7. 짐만 두고 식사하러 감
1. **짐 감지 ON**: 카메라가 사람 없음 + 짐 있음을 보내면 바로 🟧 이석(일시) · 짐만 있음, 지도 좌측 상단에 노란 점
2. **짐 감지 OFF**(사람만 판정): 🟧 이석(일시) → 관리자가 순찰 중 짐을 확인하면 좌석 상태 [짐만 있음] 지정
3. 1분 → 🟧 **이석(장기) · 사석화** `!` → 2분 더 지나면 **자동 반납**
4. 반납 뒤 남은 짐은 '짐만 있음' → 관리자 [짐 수거 완료]

### 8. 빈자리가 없음 → 빈자리 알림
1. C가 [🔔 빈자리 알림] 신청(구역 선택 가능)
2. 자리가 나면 순서대로 C에게 알림 → **1분 동안 C만 예약 가능** (다른 사람은 "다른 대기자에게 먼저 안내 중인 좌석이에요")
3. C가 예약하지 않거나 [양보]하면 다음 대기자에게 넘어간다

### 9. 두 사람이 같은 좌석을 동시에 예약
- 한 명만 성공, 다른 사람은 "이미 예약된 좌석이에요" (서버에서 좌석당 활성 예약 1개로 막음)
- 이미 예약이 있는 사람이 또 예약하면 "이미 예약한 좌석이 있어요" (1인 1석)

### 10. 친구가 QR 사진으로 대신 체크인 (자리는 비어 있음)
1. QR 사진으로 체크인 자체는 막을 수 없음 → 체크인 성공
2. 카메라가 빈 좌석으로 봄 → 🟧 이석(일시) → 1분 🟧 **장기 이석** `!` → 2분 더 지나면 **자동 반납**
3. 반복되면 관리자 [예약자 경고]

### 11. 예약석 콘센트가 고장
1. C: [관리자 호출] "콘센트가 안 돼요" → 관리자 팝업
2. 관리자: 좌석 상태 [사용불가] + 메모 → **! 예약 좌석 사용불가**, C에게 "예약 좌석을 사용할 수 없게 됐어요"
3. 관리자 [좌석 이동] → 다른 빈자리로 이동(이용 중 그대로)
4. 다른 이용자에게는 "사용할 수 없는 좌석입니다. 관리자에게 문의해 주세요."만 보인다(고장 사유는 숨김)

### 12. 외투·가방에 가려 카메라가 인식 못 함
1. 카메라 UNKNOWN → 마지막 상태(정상 이용) 유지
2. 30초 → ⬛ **판단 불가** `!`
3. 관리자 현장 확인 → [현장 확인: 사람 있음] → 🟩 정상 이용

### 13. 카메라(라즈베리파이)가 꺼짐
1. 수신이 끊긴 좌석은 마지막 상태 유지 → 30초 뒤 ⬛ **판단 불가** `!` (여러 좌석이 한꺼번에)
2. 끊긴 동안은 장기 이석·무단 점유 시간을 세지 않고 **자동 반납도 하지 않는다**
3. 관리자: 카메라 점검, 필요한 좌석은 현장 확인으로 상태 지정

### 14. 반복 위반 → 이용 정지
1. 관리자 [예약자 경고] — 경고는 누적, 본인에게 알림
2. 3회 → "이용 정지 권장" → [이용 정지](기본 3일)
3. 정지 중에는 예약·빈자리 알림 불가 ("이용 정지 중이에요")

### 15. 처음 온 사람이 좌석 QR을 찍음
1. 로그인 화면(“좌석 QR을 이용하려면 먼저 로그인해 주세요”) → [회원가입]
2. 가입하면 그 좌석 화면으로 돌아옴 → [바로 예약하기] → 예약과 체크인이 한 번에

### 16. 이용 중 자리를 옮기고 싶음
1. 옮길 좌석(빈자리)의 QR을 찍음 → "예약한 좌석은 A-1이에요" + [A-1 → B-2 바꾸기]
2. 바꾸면 A-1 반납, B-2 바로 이용(체크인)
