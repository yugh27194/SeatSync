# SeatSync 기능 안내

## 이용자

### 좌석 지도 (`/map`)
- 8석 배치도(왼쪽 2×2 · 오른쪽 2×2, **좌석만** 표시)에서 **빈자리 / 사용중 / 사용불가**를 색으로 확인하고 빈자리를 눌러 예약한다.
- **내 자리 바**: 예약 좌석, 남은 시간, 체크인 마감 카운트다운. 내 좌석에 문제가 생기면 경고 문구가 함께 뜬다
  (예: "자리를 비운 상태예요(일시 이석). 8분 뒤 '장기 이석'으로 처리됩니다").
- **좌석을 누르면**: 사용중·사용불가 좌석의 상태를 관리자 화면과 같은 이름으로 안내한다
  (예: "A-2 · 미입실 — 예약자가 체크인 시간 안에 오지 않았어요", "무단 점유", "일시 이석", "장기 이석", "짐만 있음", "사석화", "판단 불가").
  지도 색은 초록·주황·회색 3가지로만 칠한다(관리자 확인 표시는 [관리자] 탭에만).
- **지금 혼잡도**: 사용중 비율, 남은 빈자리 수.
- **빈자리 알림**: 빈자리가 없을 때 구역(왼쪽·오른쪽 또는 아무 자리)을 골라 대기한다.
  빈자리가 나면 순서대로 **5분 동안 그 사람만 예약할 수 있게** 잡아 두고 알린다. 시간이 지나거나 양보하면 다음 대기자에게 넘어간다.

### 좌석 QR (`/seat/{번호}?t=…`)
좌석에 붙은 QR을 폰으로 찍으면 열린다(로그인 후 같은 좌석으로 복귀).
- 내 예약 좌석: **[체크인]** / 이용 중이면 남은 시간·연장·반납
- 예약 없는 좌석: **[바로 예약하기]** — 예약과 동시에 체크인
- 다른 사람 예약 좌석: 안내 + **[관리자 호출]**
- 사용불가 좌석: 사유(고장·점검·청소 등) 안내

QR에는 좌석별 난수 토큰이 들어 있어, 좌석에 가지 않고는 체크인할 수 없다. 좌석마다 QR이 하나씩이라
**A-1 QR을 찍으면 A-1 좌석에 체크인**된다. 로그인하지 않았으면 로그인(또는 회원가입) 뒤 같은 좌석 페이지로 돌아온다.

**좌석 QR 보관함 (`/admin/qr`, 관리자 탭 → 좌석 QR)**
- 좌석에 붙여 둔 QR을 **그대로** 보여 준다. QR을 새로 만들거나 바꾸는 기능은 없다 — 각 좌석에 저장된 토큰으로
  처음 출력할 때와 똑같은 주소(`{서비스 주소}/seat/{번호}?t={토큰}`)를 같은 방식으로 그린다.
- 화면 자체가 **A4 한 장**(2열 × 4행 = 8석) 모양이라 바로 확인하고 **[A4로 인쇄]** 할 수 있다(배율 100%, 점선을 따라 자르기).
  QR이 떨어지거나 훼손된 좌석만 잘라 다시 붙이면 된다.
- 좌석 토큰은 DB를 다시 만들어도(`init_db --reset`) 유지된다. 좌석 QR 화면은 관리자만 볼 수 있다(토큰이 들어 있어서).

### 자동 강제 반납
| 상황 | 흐름 (기본값) |
|---|---|
| 예약하고 오지 않음 | 체크인 제한 **15분** → **! 미입실** → **15분** 더 지나면 예약 자동 취소 |
| 체크인 후 오래 자리 비움 | 일시 이석 → 장기 이석 기준 **30분** → **! 장기 이석** → **15분** 더 지나면 자동 강제 반납 |
| 짐만 두고 자리 비움 | 사석화 기준 **30분** → **! 사석화** → **15분** 더 지나면 자동 강제 반납 |

- '자동 강제 반납' 시간은 설정에서 바꾼다(0이면 끔 — 관리자가 직접 처리).
- 확인 필요(!) 동안 관리자는 먼저 처리할 수 있고, 이용자는 돌아오거나 체크인하면 된다.
- 본인에게는 기준 시간 전 사전 경고, 확인 필요가 되면 "n초/분 뒤 자동 반납" 안내, 반납되면 알림이 간다.
- 카메라가 판단하지 못하는 좌석(판단 불가)은 자동 반납하지 않는다. 자동 반납은 처리 이력에 '자동 강제 반납'으로 남는다.

### 내 자리 (`/my`)
남은 시간 카운트다운, **연장**(종료 30분 전부터, 최대 2회), **조기 반납**, **관리자 호출**(메모), 누적 경고 수, 내 좌석 경고.

### 내 이용 기록 (`/history`)
- **일별(14일)·주별(8주)·월별(6개월) 이용 시간** 막대그래프 — 체크인부터 반납까지 실제 이용 시간, 자정을 넘기면 날짜별로 나눔
- 요약: 총 이용 시간, 평균, 예약 수, 최장 이용, 연장·반납·시간 만료·미입실·강제 반납 횟수
- 예약별 **이력 타임라인**: 예약 → 체크인 → 연장(종료 시각 변화) → 반납 …
- 받은 **경고·알림 기록**

### 혼잡도 (`/congestion`)
지금 혼잡도, 오늘 시간대별 그래프, **요일×시간 히트맵**(최근 4주 평균), 가장 붐비는 때·한산한 때.

### 알림 🔔 · 사전 경고
화면을 열어 두면 몇 초 안에 배너와 🔔로 표시된다.

| 알림 | 언제 |
|---|---|
| **사전 경고** | 일시 이석·짐만 두고 비움이 장기 이석·사석화 기준 **10분 전**, 체크인 마감 10분 전, 착석했는데 체크인 전 |
| 처리 필요 전환 | 장기 이석·사석화로 표시됨, 예약 좌석 사용불가, 내 예약석에 다른 이용 확인 |
| 관리자 조치 | 사전 경고(누적 안 됨), 경고(누적), 강제 반납, 이용 정지·해제, 좌석 이동·배정 |
| 빈자리 안내 | 대기 중인 구역에 빈자리가 남, 안내 시간 만료 |
| 미입실 · 자동 반납 | 체크인 시간이 지나 미입실로 표시됨, 자동 강제 반납·취소됨 |

## 관리자 ([관리자] 탭)

관리자 계정은 따로 없다. 관리자 개입이 필요한 기능과 표시는 모두 **[관리자] 탭**에만 있고, 다른 탭(좌석 지도·내 자리·혼잡도·내 기록)은
누구에게나 같은 일반 화면이다.
- [관리자] 탭을 처음 누르면 **팝업으로 관리자 코드**를 묻는다. 맞으면 관리자 탭으로 들어간다.
- 같은 로그인(세션) 동안에는 다른 탭에 갔다가 돌아와도 **다시 묻지 않는다**(로그아웃하면 다시 물음).
- 코드를 5번 틀리면 5분 동안 잠긴다.
- 관리자 탭 메뉴: **대시보드 · 좌석 QR · 이용 분석 · 판정 기준**

**관리자 역할 범위**: 카메라·모델이 착석/이석/판단 불가를 1차로 자동 판정하고, 명확한 경우(정상 이용·일시 이석·빈자리)는
자동으로 좌석 상태에 반영한다. 기준 시간을 넘겼거나 QR 체크인과 카메라 감지가 어긋나거나(장기 이석·무단 점유·체크인 누락)
카메라가 판단하지 못하는(판단 불가) **예외만** 관리자 확인 목록에 올라온다. 관리자는 모든 좌석을 보지 않고 이 예외만 최종 확인한다.

### 대시보드 (`/admin`)
- **요약**: 정상 · 이석(일시·장기) · 무단 점유 · 판단 불가 좌석 수, 관리자 확인 수, 점유율·실사용률, 빈자리 대기 인원
- **좌석 지도 — 상태 분류 4가지**: 🟩 **정상** · 🟧 **이석**(일시/장기) · 🟥 **무단 점유** · ⬛ **판단 불가**(짙은 회색).
  칸 안에 좌석명·분류·세부 상태를 쓰고, 관리자 확인이 필요한 좌석에는 빨간 `!`. 사용불가(고장·점검)는 옅은 회색 빗금.
- **좌석을 누르면 오른쪽(휴대폰은 아래) 상세 창**
  - 지금 상태(예: "이석(일시) · 짐만 있음 · 5분째 · 24분 뒤 '사석화'"), 상태 설명, **처리 방법**, 조치 버튼
  - **좌석 상태 지정**: **빈자리 / 예약 / 사용중 / 사용불가** 네 가지
    - 예약: 이용자를 골라 예약(주황). 체크인 제한 시간 안에 아무도 오지 않으면 **! 미입실(확인 필요)**
    - 사용불가: 메모(예: 의자 파손)를 남길 수 있음
  - 예약 조치: 대리 체크인, 좌석 이동, 관리자 연장, 사전 경고, 경고(누적), 강제 반납·예약 취소
- **조치 목록**: 관리자 확인이 필요한 예외(무단 점유·장기 이석·사석화·체크인 누락·미입실·판단 불가·예약 좌석 사용불가)와 이용자 호출 — 권장 조치, 처리 완료
  - **판단 불가**: [현장 확인: 사람 있음 / 짐만 있음 / 비어 있음]으로 실제 상태를 지정하면 카메라가 회복될 때까지 그 상태로 판정한다
- **예약 대조 · 카메라** (한 표): 카메라 연결 상태(정상/끊김·마지막 수신) + 좌석마다 예약·QR 체크인 × 카메라 감지(A01 사람 있음 · n초 전) × 현장 × 판정
- **처리 이력**: 모든 조치를 언제·누가·어느 좌석·누구에게·사유와 함께 기록
- **시간대별 장기 이석·사석화 비율**
- 시연 상황 배치·샘플 기록 생성은 웹사이트에 없다. 서버를 처음 만들 때 `init_db --sample`로 한 번만 만든다.

### 이용 분석 (`/admin/congestion`)
혼잡도에 더해 **실사용률**(실제로 앉아 있는 비율), **유휴 점유**(자리만 잡고 비어 있는 비율), **처리 필요 비율** 히트맵과
"예약 대비 실사용 n%" 지표. (일반 [혼잡도] 탭에는 점유율만 보인다)

### 판정 기준 (`/admin/settings`)
체크인 제한, **장기 이석·사석화·무단 점유·판단 불가 기준**, **자동 강제 반납**, 이용·연장 시간, 연장 가능 시점·횟수, 정지 권장 경고 수·기본 정지 기간,
사전 경고 시점, 빈자리 안내 유지 시간, 운영 시간.
- 시간 값은 **15초 단위**(분 + 0/15/30/45초)로 정한다.
- 기본값(운영): 장기 이석 30분 · 사석화 30분 · 무단 점유 10분 · 판단 불가 3분 · 자동 반납 15분.
- **[시연 모드]**(약 3분 시연용): 체크인 제한 1분 · 장기 이석/사석화 30초 · 무단 점유 30초 · 판단 불가 15초 · 자동 반납 30초 · 사전 경고 15초 전 · 빈자리 안내 1분.
  값만 채우므로 [저장]을 눌러야 적용된다.

## 좌석 상태 요약

**관리자 탭 상태 분류**

| 색 | 분류 | 세부 상태 |
|---|---|---|
| 🟩 초록 | 정상 | 정상 이용 · 빈자리 · 입실 대기 · 착석 감지/착석(체크인 전) |
| 🟧 주황 | 이석 (일시 / 장기) | 일시: 일시 이석 · 짐만 있음 / 장기: ! 장기 이석 · ! 사석화 · ! 미입실 |
| 🟥 빨강 | 무단 점유 | ! 무단 점유 · ! 체크인 누락 |
| ⬛ 짙은 회색 | 판단 불가 | ! 판단 불가 (카메라 인식 오류) |

**이용자 좌석 지도**: 🟩 빈자리 · 🟧 사용중 · ⬜ 사용불가

| 좌석 상태 | 세부 상태 (! = 조치 목록에 오름) |
|---|---|
| **빈자리** | 빈자리 |
| **사용중** | 정상 이용 · 입실 대기 · 착석 감지(체크인 전) · 착석(체크인 전) · 일시 이석 · 짐만 있음 · ! 무단 점유 · ! 체크인 누락 · ! 미입실 · ! 장기 이석 · ! 사석화 · ! 판단 불가 |
| **사용불가** | 고장 · 점검·청소 · 사용 중지 · ! 예약 좌석 사용불가 |

일반 이용자에게는 초록·주황·회색 3가지만 보인다(내 좌석의 경고는 본인에게만).
