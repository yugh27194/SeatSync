# SeatSync 기능 안내

## 이용자

### 좌석 지도 (`/map`)
- 8석 배치도(왼쪽 2×2 · 통로 · 오른쪽 2×2, 창문·출입문·안내데스크 포함)에서 **빈자리 / 사용중 / 사용불가**를 색으로 확인하고 빈자리를 눌러 예약한다.
- **내 자리 바**: 예약 좌석, 남은 시간, 체크인 마감 카운트다운. 내 좌석에 문제가 생기면 경고 문구가 함께 뜬다
  (예: "자리를 비운 상태예요. 8분 뒤 '이탈'로 처리됩니다").
- **지금 혼잡도**: 사용중 비율, 남은 빈자리 수.
- **빈자리 알림**: 빈자리가 없을 때 구역(왼쪽·오른쪽 또는 아무 자리)을 골라 대기한다.
  빈자리가 나면 순서대로 **5분 동안 그 사람만 예약할 수 있게** 잡아 두고 알린다. 시간이 지나거나 양보하면 다음 대기자에게 넘어간다.

### 좌석 QR (`/seat/{번호}?t=…`)
좌석에 붙은 QR을 폰으로 찍으면 열린다(로그인 후 같은 좌석으로 복귀).
- 내 예약 좌석: **[체크인]** / 이용 중이면 남은 시간·연장·반납
- 예약 없는 좌석: **[바로 예약하기]** — 예약과 동시에 체크인
- 다른 사람 예약 좌석: 안내 + **[관리자 호출]**
- 사용불가 좌석: 사유(고장·점검·청소 등) 안내

QR에는 좌석별 난수 토큰이 들어 있어, 좌석에 가지 않고는 체크인할 수 없다.

### 내 자리 (`/my`)
남은 시간 카운트다운, **연장**(종료 30분 전부터, 최대 2회), **조기 반납**, **관리자 호출**(메모), 누적 경고 수, 내 좌석 경고.

### 내 이용 기록 (`/history`)
- **일별(14일)·주별(8주)·월별(6개월) 이용 시간** 막대그래프 — 체크인부터 반납까지 실제 이용 시간, 자정을 넘기면 날짜별로 나눔
- 요약: 총 이용 시간, 평균, 예약 수, 최장 이용, 연장·반납·시간 만료·미입실·강제 반납 횟수
- 예약별 **이력 타임라인**: 예약 → 체크인 → 연장(종료 시각 변화) → 반납 …
- 받은 **경고·알림 기록**

### 혼잡도 (`/congestion`)
지금 혼잡도, 오늘 시간대별 그래프, **요일×시간 히트맵**(최근 4주 평균), 가장 붐비는 때·한산한 때.

### 알림 🔔 · 사전 경고
화면을 열어 두면 몇 초 안에 배너와 🔔로 표시된다.

| 알림 | 언제 |
|---|---|
| **사전 경고** | 자리를 비움·짐만 두고 비움이 이탈·사석화 기준 **10분 전**, 체크인 마감 10분 전, 착석했는데 체크인 전 |
| 처리 필요 전환 | 이탈·사석화로 표시됨, 예약 좌석 사용불가, 내 예약석에 다른 이용 확인 |
| 관리자 조치 | 사전 경고(누적 안 됨), 경고(누적), 강제 반납, 이용 정지·해제, 좌석 이동·배정 |
| 빈자리 안내 | 대기 중인 구역에 빈자리가 남, 안내 시간 만료 |
| 미입실 | 체크인 시간이 지나 미입실로 표시됨, 관리자가 예약 취소 |

## 관리자 (관리자 모드)

관리자 계정은 따로 없다. 상단 **[관리자] 스위치**를 켜고 관리자 코드를 입력하면 관리자 모드가 되고, 끄면 일반 화면으로 돌아간다.
관리자 모드에서는 이석·짐만 있음·무단 점유·미입실 등 **확인이 필요한 좌석이 붉게 강조되고 빨간 `!`** 가 붙으며, 하단에 **관리**·**설정** 탭이 생긴다.

### 대시보드 (`/admin`) — 하단 **관리** 탭
- **요약**: 빈자리·사용중·사용불가·확인 필요 수, 점유율·실사용률, 빈자리 대기 인원
- **좌석 지도**: 칸 안에는 **좌석명만** 표시. 초록 빈자리 · 주황 사용중(예약 포함) · 회색 사용불가, 확인 필요 좌석은 붉은 주황 + 빨간 `!`
- **좌석을 누르면 오른쪽(휴대폰은 아래) 상세 창**
  - 지금 상태(예: "사용중 · 짐만 있음 · 5분째 · 24분 뒤 '사석화'"), 상태 설명, **처리 방법**, 조치 버튼
  - **좌석 상태 지정**: **빈자리 / 예약 / 사용중 / 사용불가** 네 가지
    - 예약: 이용자를 골라 예약(주황). 체크인 제한 시간 안에 아무도 오지 않으면 **! 미입실(확인 필요)**
    - 사용불가: 메모(예: 의자 파손)를 남길 수 있음
  - 예약 조치: 대리 체크인, 좌석 이동, 관리자 연장, 사전 경고, 경고(누적), 강제 반납·예약 취소
- **조치 목록**: 기준 시간을 넘긴 문제(무단 점유·이탈·사석화·체크인 누락·미입실·예약 좌석 사용불가)와 이용자 호출 — 권장 조치, 처리 완료
- **예약 대조 · 카메라** (한 표): 카메라 연결 상태(정상/끊김·마지막 수신) + 좌석마다 예약 × 카메라 감지(A01 사람 있음 · n초 전) × 현장 × 상태
- **처리 이력**: 모든 조치를 언제·누가·어느 좌석·누구에게·사유와 함께 기록
- **시간대별 이탈·사석화 비율**, 시연 상황 배치, 샘플 이력 생성

### 혼잡도 (관리자 모드)
점유율 외에 **실사용률**(실제로 앉아 있는 비율), **유휴 점유**(자리만 잡고 비어 있는 비율), **처리 필요 비율** 히트맵과
"예약 대비 실사용 n%" 지표.

### 설정 (`/admin/settings`) — 하단 **설정** 탭
체크인 제한, 이탈·사석화 기준, 이용·연장 시간, 연장 가능 시점·횟수, 정지 권장 경고 수·기본 정지 기간,
사전 경고 시점, 빈자리 안내 유지 시간, 운영 시간. [시연 모드]로 기준 시간을 짧게 채울 수 있다.

## 좌석 상태 요약

**좌석 색**

| 색 | 뜻 |
|---|---|
| 🟩 초록 | 빈자리 (예약 가능) |
| 🟧 주황 | 사용중 |
| ⬜ 회색 | 사용불가 |
| 🟥 붉은 주황 + 빨간 `!` | **확인 필요** — 이석(잠시 자리 비움·이탈)·짐만 있음·사석화·무단 점유 등. 관리자 모드에서만 보이고, 좌석을 누르면 어떤 상태인지와 처리 방법이 나온다 |

| 좌석 상태 | 세부 상태 (! = 조치 목록에 오름) |
|---|---|
| **빈자리** | 빈자리 |
| **사용중** | 이용 중 · 입실 대기 · 착석(체크인 전) · 잠시 자리 비움 · 짐만 있음 · ! 무단 점유 · ! 체크인 누락 · ! 이탈 · ! 사석화 |
| **사용불가** | 고장 · 점검·청소 · 사용 중지 · ! 예약 좌석 사용불가 |

일반 이용자에게는 초록·주황·회색 3가지만 보인다(내 좌석의 경고는 본인에게만).
